# aqs_isavailable

**\[stable\]** returns a tibble that details the status of the AQS Data
Mart API.

## Usage

``` r
aqs_isavailable()
```

## Value

a tibble that details the status of the AQS Data Mart API.

## Examples

``` r
  # Check if the AQS API is up, running and accepting requests.
  if (FALSE)  aqs_isAvailable()  # \dontrun{}
```
